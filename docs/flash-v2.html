🔒 Secure Setup: Traditional setup method via device AP mode
WiFi credentials never leave your device. Recommended for maximum security.
How it works:
  1. Flash firmware to device
  2. Device creates its own WiFi network (DataTracker-XXXX)
  3. Connect to device's network and configure
  4. Your credentials stay secure on the device
⚠️ Requirements:
  • Chrome 89+ or Edge 89+ browser
  • ESP32-C3 connected via USB cable
  • USB data cable (not just charging cable)
✅ After Flashing:
  1. Look for WiFi network: DataTracker-XXXX
  2. Connect with password shown on device display
  3. Browser opens setup page (or visit 192.168.4.1)
  4. Configure WiFi and select modules
  5. Save and enjoy!
